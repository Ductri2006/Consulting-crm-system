# Advisora Public Website

The `client` directory contains the responsive public website for the Consulting CRM System portfolio project. Advisora is a fictional consulting brand used for the demonstration interface.

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- React Hook Form
- Zod
- Lucide React

## Local Development

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

The current version uses typed mock data and does not call a backend API.
